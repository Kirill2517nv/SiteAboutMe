# Textbook API

Учебник смонтирован на `/textbook/` (`textbook/urls.py`) – **7 endpoint'ов**.
Одна модель `Article` обслуживает три трека: `material` (уроки), `ege` (теория
к заданиям 1–27) и `spetskurs`. Разбор статей по треку `ege` живёт в
[EGE API](ege.md), спецкурсный – в [Spetskurs API](spetskurs.md); здесь описаны
маршруты самого учебника.

---

## Endpoints

### GET `/textbook/` – Главная учебника

**View:** `textbook_home_view`
**Auth:** Не требуется
**Template:** `textbook/textbook_home.html`

Аккордеон по блокам (`Section`) с прогрессом и шкалами практикума и
самопроверок. По умолчанию раскрыт блок, где стоит фишка самого зрителя, – то
же правило, по которому учитель видит аватарки класса на маршруте главной.
У учителя и у ученика без класса фишки нет, таким раскрывается первый блок.

**Контекст:**

| Переменная | Описание |
|------------|----------|
| `material_sections` | Блоки со статьями, прогрессом, дедлайном и оценкой |
| `student_groups` | Панель выбора классов (только суперпользователю) |
| `total_lessons` / `total_done` / `progress_pct` | Сводка по всему курсу |

Статьи всех блоков забираются одним `Prefetch` – карточка блока не стоит
отдельного запроса.

### GET `/textbook/article/<slug>/` – Статья

**View:** `article_detail_view`
**Auth:** Не требуется; черновик виден только суперпользователю
**Template:** `textbook/article_detail.html`

Содержимое статьи – блоки (`ArticleBlock`) плюс самопроверки, сайдбар и
навигация. Видимость решает `visible_articles(request.user)`: суперпользователь
получает всё, остальные – только опубликованные статьи, да и то не из скрытого
блока (`Section.is_published=False`): URL статьи предсказуем, и без этого фильтра
неготовый блок открывался бы по прямой ссылке. Соседи в сайдбаре считаются
**той же** функцией, иначе у черновика, открытого автором, список не содержал бы
самой открытой статьи и `prev/next` показывали бы соседей чужой статьи.

Блоки фильтрует `visible_blocks` по своей оси (`ArticleBlock.visibility`):
`teacher` – только учителю, `students` – вошедшим, `all` – всем. Гость закрытого
разбора не видит никогда, даже открытого ученикам: страница доступна без входа,
и решение в открытом интернете перестаёт быть заданием. Ученику на месте
закрытого разбора остаётся заглушка «разберём на занятии».

Трек статьи задаёт и группу соседей, и адрес кнопки «назад»:

| Трек | Соседи | Назад |
|------|--------|-------|
| `ege` | статьи того же `EgeTask` | карточка задания `/ege/task/<N>/` |
| `spetskurs` с задачей | статьи той же `CourseTask` | страница задачи |
| `spetskurs` без задачи | все статьи «Основ C++» | `/spetskurs/basics/` |
| `material` | статьи того же блока | `/textbook/` |

Вошедшему ученику открытие статьи ставит `ArticleProgress` (`get_or_create`) –
отсюда растёт «прочитано» в профиле.

**Контекст:**

| Переменная | Описание |
|------------|----------|
| `article` | Статья |
| `blocks` | Видимые блоки статьи |
| `has_widgets` | Есть ли блок-виджет – под этим флагом шаблон грузит реестр виджетов |
| `self_checks` | Микротесты с числом верных ответов и цветом |
| `progress` | `ArticleProgress` ученика или None |
| `frontier` | Фишки одноклассников, остановившихся на этой статье |
| `sidebar_items` | Соседи с их статусом чтения и цветом галочки |
| `practicum` | Практикум блока: ссылка, прогресс, шкала оценки |
| `group_title`, `article_number`, `back_url`, `back_label` | Шапка и навигация |
| `prev_article`, `next_article` | Соседи по сайдбару |

!!! info "Размеры картинок считаются во вьюхе"
    `block.pswp_size` читается из самого файла: PhotoSwipe открывает снимок в
    тех пропорциях, что стоят в `data`-атрибутах. Чтение обёрнуто в `try` –
    битая иллюстрация не должна ронять страницу.

### POST `/textbook/article/<slug>/read/` – Отметить прочитанной

**View:** `mark_article_read_view`
**Auth:** `@login_required`
**Response:** `JsonResponse` · `{"status": "read"}`

Вызывается из JS, когда ученик долистал статью до конца. Статус не понижается:
`mastered` (освоено самопроверкой) остаётся, если он уже стоит.

---

### POST `/textbook/article/<slug>/time/` – Время чтения

**View:** `track_reading_time_view`
**Auth:** `@login_required`
**Response:** `JsonResponse` · `{"ok": true}`

Копит `ArticleProgress.time_spent_seconds`. JS присылает порции по несколько
десятков секунд, только пока вкладка активна.

Порция ограничена сверху дважды: константой 300 с и временем, прошедшим с
прошлой порции. Клиентский таймер подкручивается, серверные часы – нет; без
этого цикл `POST`'ов с `seconds=300` рисовал бы в отчёте учителю любое время
чтения.

### POST `/textbook/block/<pk>/visibility/` – Рубильник разбора

**View:** `block_visibility_toggle_view`
**Auth:** `@login_required` + `is_superuser` (иначе 403)
**Response:** редирект на статью блока

Переключает `ArticleBlock.visibility` между `teacher` и `students` – то же поле,
что и в админке, но рубильник нужен посреди занятия: разобрали задание у доски
и открыли разбор всем, кто вошёл. Прецедент тот же, что у набора задач в классе
(`ege_classroom_toggle`).

Трогать можно только блоки с `is_solution=True`; у обычного текста закрытого
состояния нет, для него возвращается 404.

### GET `/textbook/section/<slug>/stats/` – Отчёт учителя по блоку

**View:** `section_stats_view`
**Auth:** `is_superuser` (иначе 403)
**Template:** `textbook/section_stats.html`

Таблица учеников по классам: оценка, решённые задачи практикума, самопроверки,
прочитанные статьи, время чтения и решения, счётчик ошибок. **Один класс за
раз** – `?group=<id>`, вкладки над таблицей; `none` – «Без группы», `all` – все
сразу. Мусор в `?group=` трактуется как «все», а не как 404 – ссылка на класс
переживает удаление класса.

Строки сортируются в Python по той же строке, что стоит в ячейке
(`surname_first`: «Фамилия Имя», иначе логин; ё = е), а не `order_by('last_name')`:
тот ставил учеников без фамилии в начало, хотя в таблице у них логин.

Фамилия ведёт не в профиль, а в разбор ответов – `answers_url` строки.

### GET `/textbook/section/<slug>/stats/<user_id>/errors/` – Разбор ответов

**View:** `section_stats_errors_view`
**Auth:** `is_superuser` (иначе 403)
**Template:** `textbook/section_stats_errors.html`

Что ученик решил и на чём спотыкается. У страницы два независимых среза, и они
складываются:

| Параметр | Значение |
|----------|----------|
| `?errors=1` | Только ошибки (на это ведёт счётчик ошибок в таблице) |
| `?kind=practicum` | Задачи практикума |
| `?kind=selfcheck` | Вопросы самопроверок |

Домашнюю задачу решают, вопрос по ходу чтения щёлкают – в одном списке их
сравнивать не с чем. Адреса вкладок собираются во вьюхе, а не в шаблоне: у
страницы два параметра, и каждая вкладка обязана сохранить второй.

Ответы группируются по вопросу, а не по попытке: важно, что с задачей, а не
сколько раз ученик отвечал. «Решена ли задача» считается по **всем** ответам, а
не по показанным – в режиме ошибок верной попытки в выборке нет, а «решил
позже» показать надо.
