# Pages API

Приложение `pages` обслуживает главную, about-страницу и историю версий. Две
первые подключены прямо в `config/urls.py` (`/` и `/about/`), третья –
в `pages/urls.py` (`/pages/changelog/`). Контент-блоки управляются через Django
Admin.

---

## Endpoints

### GET `/` – Главная страница

**View:** `home_page_view`
**Auth:** Не требуется
**Template:** `home.html`

Карта курса: маршрут по всем блокам учебника с прогрессом. Данные приходят из
`textbook.services.course_map()` – главная читает те же строки, что и учебник,
поэтому числа на двух страницах не расходятся.

**Логика раскладки:**

- Блоки, помеченные `is_soon` (черновики), на карте не рисуются; вместо них в
  конце маршрута стоит одна карточка «скоро».
- Сетка «змейкой»: нечётные ряды слева направо, чётные – справа налево, поэтому
  маршрут читается одной непрерывной линией. Номер ряда и колонки считаются во
  вьюхе: `{% cycle %}` не умеет разворачивать порядок.
- `frontier_positions()` по видимым классам расставляет фишки одноклассников –
  у кого маршрут остановился на каком уроке. Аноним не видит никого.

**Контекст:**

| Переменная | Описание |
|------------|----------|
| `rows` | Блоки курса с уроками, прогрессом и фишками |
| `soon` | Координаты карточки «скоро» (или None) |
| `lines`, `turns` | Геометрия пунктирных и разворотных линий маршрута |
| `current` | Блок, где зритель стоит сейчас |
| `has_pins` | Есть ли хоть одна фишка – место под ряд аватарок |
| `student_groups` | Панель выбора классов (только суперпользователю) |
| `section_label`, `lesson_label` | Подписи со склонением («21 блок», «152 статьи») |

### GET `/pages/changelog/` – История версий

**View:** `changelog_view`
**Auth:** Не требуется
**Template:** `changelog.html`

Отдаёт `parse_changelog()` – разбор `CHANGELOG.md` в структуру версий,
категорий и элементов. Раньше история жила на главной, теперь это отдельная
страница.

---

### GET `/about/` – О проекте

**View:** `about_page_view`
**Auth:** Не требуется
**Template:** `about.html`

Загружает автора (`AuthorProfile` с `is_active=True` – берётся первый) и его
медиа, делит события на три группы и добавляет контент-блоки.

**Контекст:**

| Переменная | Описание |
|------------|----------|
| `profile` | `AuthorProfile` или None |
| `photos` | `AuthorPhoto` с `is_visible=True` |
| `videos` | `AuthorVideo` с `is_visible=True` |
| `education` | `AuthorEvent(event_type='education')` |
| `publications` | `AuthorEvent(event_type='publication')` |
| `conferences` | `AuthorEvent(event_type='conference')` |
| `blocks` | QuerySet `ContentBlock` с `page='about'`, по `order` |
| `page_type` | `'about'` |
