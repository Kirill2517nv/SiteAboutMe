# Эффекты мастер-класса: что выставить, чтобы увидеть

Таблица – вывод `GuiLibrary/MasterClass/check_effects.py`: скрипт повторяет шаги
симуляций `MK_*.cpp` во float32 (как `float` в сборке) и проверяет каждую строку
`assert`-ом. Руками таблицу не править: поменяли модель или значения по умолчанию –
прогоните скрипт и вставьте вывод заново.

```
python MasterClass/check_effects.py      # из папки GuiLibrary, нужен numpy
```
